# My Planner

Power List, 12 Week Year, Calendar & Deadlines and an Inspiration board in one page.

**Live:** https://sanusi06abdul-ux.github.io/planner/

- Data is not stored in this repository. It lives in your browser and, once sync is set up (⋯ → Set up sync), in a "My Planner sync" folder in your own Google Drive.
- Deadlines are copied to a "Planner deadlines" Google Calendar by the sync script.
- To update the site, replace `index.html`.
